# Contributing

1. Take your task issue (one per member, labelled `contribution`).
2. Work on a branch named `<your-name>/<topic>`, never directly on `main`.
3. Commit in small steps with clear messages ("Add NPO baseline", not "final").
4. Open a pull request. A **different** team member reviews it and leaves a real comment.
5. Merge after approval. `main` is protected: nothing lands without a review.

Do not commit model checkpoints, large data files or credentials — link the Google Drive folder instead.
